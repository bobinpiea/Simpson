📺 Site Web – Les Simpson

Ce projet a été réalisé dans le cadre de la formation Développeur Web & Web Mobile chez Elan Formation.

⸻

🎯 Objectif

L’objectif de ce premier exercice était de créer une page web simple sur le thème des Simpson, en utilisant uniquement HTML et CSS.
Il s’agissait avant tout d’un projet d’initiation, destiné à comprendre la structure d’une page web, les balises de base, ainsi que les premières notions de mise en page.

⸻

📄 Contenu du site

Le site se compose de plusieurs parties :
	•	Un en-tête (header) avec un titre et une image représentant la famille Simpson.
	•	Une barre de navigation latérale proposant plusieurs liens : Accueil, Le film, Personnages, Histoire, Matt Groening.
	•	Un article principal décrivant la série.
	•	Un encadré latéral (aside) dédié au créateur Matt Groening, avec une photo et un court texte de présentation.
	•	Un pied de page (footer) affichant la mention © 2015 The Simpsons Elan.

⸻

💻 Technologies utilisées
	•	HTML5
	•	CSS3
	•	Flexbox pour la mise en page
	•	Media queries pour une première adaptation sur tablette et mobile

⸻

🧠 Compétences développées

Ce projet a permis de :
	•	Découvrir et comprendre la structure d’un document HTML sémantique ;
	•	Utiliser les balises principales pour organiser le contenu ;
	•	Mettre en forme les éléments avec le CSS ;
	•	Expérimenter Flexbox pour disposer les blocs ;
	•	Appliquer les media queries pour adapter la page sur différents écrans.

⸻

👨‍🎓 Contexte de formation

Ce travail a été réalisé dans le cadre de ma formation Développeur Web & Web Mobile à Elan Formation, lors de la première phase d’apprentissage consacrée aux bases du HTML et du CSS.
